# Poker Hand HUD

**Модуль для FoundryVTT, отображающий карты в виде покерной руки с интерактивными эффектами**

## 📋 Описание

Poker Hand HUD - это модуль для FoundryVTT, который предоставляет элегантный интерфейс для отображения карт персонажей в виде покерной руки. Модуль поддерживает интерактивные hover эффекты, звуковые сопровождения, настраиваемый внешний вид и различные визуальные эффекты.

## 🚀 Возможности

### Основные функции
- 🃏 **Отображение карт** в виде покерной руки с красивой анимацией
- 🖱️ **Интерактивные hover эффекты** с 3D трансформациями
- 📝 **Tooltip'ы** с описанием карт при наведении
- 🔊 **Звуковые эффекты** для взаимодействия
- ✨ **Визуальные эффекты** (искры, свечение)
- 📱 **Адаптивный интерфейс** с настраиваемыми размерами

### Настройки
- 🎨 **Настройка цветов** HUD, акцентов, текста
- 📏 **Настройка размеров** карт и расстояний между ними
- 🔄 **Настройка анимаций** и эффектов
- 🔇 **Настройка звуков** и их громкости
- 📐 **Настройка positioned** элементов интерфейса

### Управление
- 📌 **Закладка** для быстрого показа/скрытия HUD
- 🔄 **Сворачивание** всего интерфейса
- 🎯 **Клик по картам** для использования в чате

### Кодовая архитектура

Модуль построен на модульной архитектуре с четким разделением ответственности:

#### Основные системы

**PokerHandHUD** - Основное приложение
- `init()` - Инициализация HUD
- `buildHTML()` - Создание HTML структуры
- `renderCards()` - Отрисовка карт
- `injectCSS()` - Внедрение стилей
- `setupCleanup()` - Настройка очистки

**ConfigSystem** - Управление конфигурацией
- `createDefaultConfig()` - Создание конфигурации по умолчанию
- `loadSettings()` - Загрузка настроек из FoundryVTT

**CardSystem** - Работа с картами
- `useCardAndChat()` - Использование карты и отправка в чат
- `selectCardHand()` - Выбор руки карт

**UIManager** - Управление интерфейсом
- `setupSettingsIntegration()` - Интеграция с настройками
- `updateBookmarkPosition()` - Обновление позиции закладки

**StateManager** - Управление состоянием
- `getGlobalCollapsed()` - Получение состояния сворачивания
- `setGlobalCollapsed()` - Установка состояния сворачивания
- `applyGlobalCollapse()` - Применение сворачивания

**Utils** - Утилитарные функции
- `hexToRgba()` - Конвертация цветов
- `getSettingSafe()` - Безопасное получение настроек
- `scheduleRebuild()` - Планирование перестроения

**SoundEffects** - Звуковая система
- `load()` - Загрузка звуков
- `play()` - Воспроизведение звуков

**SparklesSystem** - Визуальные эффекты
- `setup()` - Настройка эффектов
- `getRates()` - Получение частоты эффектов

## 🛠️ Установка

1. Скачайте модуль из [FoundryVTT Community] или [GitHub]
2. Распакуйте в `Data/modules/`
3. Перезапустите FoundryVTT
4. Активируйте модуль в настройках мира
5. Настройте параметры в System Settings

## ⚙️ Настройки

### Основные настройки
- **Enable Poker Hand HUD** - Включение/выключение модуля
- **Opt Out (Local)** - Локальное отключение для пользователя

### Визуальные настройки
- **HUD Background Color** - Цвет фона HUD
- **Accent Color** - Цвет акцентов
- **Label Color** - Цвет надписей
- **Text Color** - Цвет текста
- **Selected Glow Color** - Цвет свечения выбранных карт

### Настройки компоновки
- **Max Visible Cards in Hand** - Максимальное количество видимых карт
- **Card Spacing** - Расстояние между картами
- **Hand Arc Height** - Высота дуги руки
- **Card Rotation Factor** - Коэффициент вращения карт

### Настройки эффектов
- **Sparkle Style** - Стиль визуальных эффектов
- **Sparkle Intensity** - Интенсивность эффектов
- **Enable SFX** - Включение звуковых эффектов
- **SFX Volume** - Громкость звуков

## 🎮 Использование

### Базовое использование
1. Убедитесь что у вас есть доступ к руке карт
2. HUD автоматически отобразится внизу экрана
3. Наводите на карты для просмотра tooltip'ов
4. Кликайте по картам для использования в чате

### Управление интерфейсом
- **Закладка слева** - Показать/скрыть HUD
- **Hover на картах** - Увеличение и 3D эффекты
- **Клик по карте** - Использование карты

## 🐛 Устранение неполадок

### Частые проблемы

**HUD не отображается**
- Проверьте что модуль включен в настройках мира
- Убедитесь что у вас есть доступ к руке карт
- Проверьте консоль на наличие ошибок

**Карты не отображаются**
- Убедитесь что в руке есть карты
- Проверьте права доступа к картам
- Перезагрузите страницу

**Звуки не работают**
- Проверьте что SFX включены в настройках
- Убедитесь что громкость не на нуле
- Проверьте URL аудиофайлов

**Эффекты не работают**
- Проверьте стиль эффектов в настройках
- Убедитесь что интенсивность не "none"
- Проверьте производительность браузера

### Отладка
Для отладки используйте консоль браузера (F12):

```javascript
// Проверить состояние модуля
console.log(pokerHandGlobalState);

// Проверить настройки
console.log(game.settings.get("poker-hand-hud"));

// Принудительная перезагрузка
PokerHandHUD.init();
```
