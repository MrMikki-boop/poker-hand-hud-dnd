# 🎴 GM Card Distributor - Система раздачи карт для ГМа

## 📋 Обзор

Новая функция для ГМов, позволяющая раздавать случайные карты игрокам с интерактивным выбором. Игроки получают 3 случайные карты из выбранной колоды и выбирают одну.

## 🚀 Как использовать

### 1. Доступ к функции
- Кнопка **"🎴 Раздать карты"** появляется в списке игроков (только для ГМа)
- Нажмите на кнопку для открытия диалога раздачи

### 2. Диалог раздачи карт
В диалоге ГМ может:

#### 👥 Выбор игроков
- Отметьте одного или нескольких игроков чекбоксами
- Только активные игроки с ролью "Player" доступны для выбора

#### 🎴 Выбор колоды
- Выберите колоду из выпадающего списка
- Система автоматически сканирует папку `Новые карты/` на наличие колод
- Исключаются системные папки (Лицо, Рубашка, Back, Face)

#### ⚙️ Настройки
- Укажите количество карт для раздачи (по умолчанию 3)
- Минимум 1, максимум 10 карт

### 3. Процесс раздачи
1. ГМ нажимает **"🎴 Раздать карты"**
2. Система выбирает случайные карты из указанной колоды
3. Каждому выбранному игроку отправляется личное сообщение с картами
4. Игроки видят анимированное появление карт

## 🎮 Для игроков

### Получение карт
- Игрок получает личное сообщение в чате
- Показаны 3 карты рубашкой вверх с номерами
- Карты появляются с плавной анимацией

### Выбор карты
- Кликните на любую карту для выбора
- Остальные карты затемняются
- Выбранная карта переворачивается лицевой стороной

### Результат
- Выбранная карта отображается в общем чате
- Если доступен модуль "Orcnog Card Viewer" - карта открывается в отдельном окне
- Сообщение содержит имя игрока, название колоды и изображение карты

## 🐛 Устранение неполадок

### Нет кнопки "Раздать карты"
- Убедитесь, что вы вошли как ГМ
- Проверьте, что модуль активен

### Нет доступных колод
- Проверьте наличие папки `Новые карты/`
- Убедитесь, что в папке есть подпапки с названиями колод
- Проверьте права доступа к файлам

### Карты не отображаются
- Проверьте форматы изображений (jpg, png, webp)
- Убедитесь, что пути к файлам корректны
- Проверьте консоль на наличие ошибок

### Игроки не получают карты
- Убедитесь, что игроки онлайн
- Проверьте, что у игроков есть права на получение личных сообщений
