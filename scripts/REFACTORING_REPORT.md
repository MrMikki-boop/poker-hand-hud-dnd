### 3. Исправленные проблемы

#### 🔧 Циклические зависимости:
- **Проблема**: `card-system.js` вызывал `PokerHandHUD.renderCards()`
- **Решение**: Использование `globalThis.PokerHandHUD` для избежания циклических импортов

#### 🔧 Глобальные функции:
- **Проблема**: Функции в `utils.js` вызывали недоступные функции
- **Решение**: Экспорт всех legacy функций в `globalThis` из `main.js`

#### 🔧 Дублирование импортов:
- **Проблема**: Дублирующиеся импорты в `state-manager.js`
- **Решение**: Объединение импортов в одну строку

#### 🔧 Вызовы в settings:
- **Проблема**: Функции обратного вызова в настройках были недоступны
- **Решение**: Использование `globalThis` для доступа к функциям

### 4. Обновление конфигурации
- **`module.json`** обновлен для использования новой точки входа `scripts/main.js`
