- Интеграция с Orcnog Card Viewer

## 🚀 Установка и обновление

### Новая установка
1. Скачайте модуль версии 2.0.0+
2. Распакуйте в директорию модулей Foundry VTT
3. Активируйте в настройках мира

### Обновление с версии 1.x
1. Сделайте резервную копию текущей версии
2. Замените файлы на новую версию
3. Модуль автоматически обновится при следующем запуске

### Возврат к предыдущей версии
1. Удалите файлы версии 2.0.0+
2. Переименуйте `poker-hand-hud-dnd5e.js.backup` в `poker-hand-hud-dnd5e.js`
3. Измените `module.json`:
   ```json
   "esmodules": ["scripts/poker-hand-hud-dnd5e.js"]
   ```
