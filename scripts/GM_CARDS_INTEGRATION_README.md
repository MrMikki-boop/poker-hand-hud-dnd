# 🎴 GM Card Distributor V2 - Интеграция с Foundry Cards

## 🔄 Обновление: Работа с реальными картами Foundry VTT

### 📋 Что изменилось

**Важно:** Система теперь работает с готовыми картами из колод Foundry VTT, а не с изображениями!

### 🎴 Как работает новая система

#### 1. Источник карт
- **Раньше:** Изображения из папок `Новые карты/`
- **Теперь:** Готовые карты из системы **Cards** Foundry VTT

#### 2. Процесс раздачи
1. **ГМ выбирает колоду** из списка всех доступных колод в мире
2. **Система выбирает** случайные карты из реальной колоды
3. **Игроки выбирают** одну карту из предложенных
4. **Выбранная карта создается** в инвентаре игрока как реальный предмет

### 🚀 Новые возможности

#### ✅ Преимущества:
- **Настоящие карты** - создаются как предметы в инвентаре
- **Сохранение данных** - все свойства карт сохраняются
- **Интеграция с системами** - карты работают с D&D5e и другими системами
- **Автоматическое управление** - карты добавляются в руки игроков

#### 📋 Функционал:
- Выбор из **реальных колод** Foundry VTT
- Показ **названий и описаний** карт
- **Изображения карт** если они есть
- **Создание копий** карт в инвентаре игроков

### 🎮 Для игроков

#### Получение карт:
- Игроки видят **названия карт** и описания
- Показываются **изображения** если они есть
- Выбранная карта **добавляется в инвентарь**

#### Использование карт:
- Карты появляются в **руках игроков** (Cards system)
- Можно использовать через **Poker Hand HUD**
- Интегрируются с **системой правил** (D&D5e)

### 🛠️ Требования

#### Обязательные:
- **Foundry VTT Cards system** - должна быть включена
- **Созданные колоды** - хотя бы одна колода с картами
- **Права ГМа** - для раздачи карт

#### Рекомендуемые:
- **Изображения карт** - для визуального представления
- **Описания карт** - для лучшего понимания

### 📁 Подготовка колод

#### Создание колоды в Foundry VTT:

1. **Откройте Cards tab** в навигации
2. **Создайте новую колоду** (Deck)
3. **Добавьте карты** в колоду:
   - Название карты
   - Описание (опционально)
   - Изображение (опционально)
   - Другие свойства

#### Пример структуры:
```
Cards Tab:
├── 🎴 Заклинания (Deck)
│   ├── 🔥 Огненный шар
│   ├── 💚 Лечение легких ран
│   └── ⚡ Молния
├── 🗡️ Оружие (Deck)
│   ├── ⚔️ Длинный меч
│   ├── 🏹 Лук
│   └── 🛡️ Щит
```

### 🎯 Процесс использования

#### Для ГМа:
1. **Нажмите кнопку** "🎴 Раздать карты"
2. **Выберите игроков** для раздачи
3. **Выберите колоду** из выпадающего списка
4. **Укажите количество** карт (1-10)
5. **Нажмите "Раздать карты"**

#### Для игроков:
1. **Получите сообщение** с выбором карт
2. **Изучите карты** - названия, описания, изображения
3. **Выберите одну карту** кликом
4. **Найдите карту** в своем инвентаре/руках

### 🔧 Технические детали

#### Создание карт:
- **Копирование** - создается копия карты из колоды
- **Владелец** - устанавливается игрок
- **Расположение** - добавляется в инвентарь актора
- **Сохранение** - все свойства оригинальной карты

#### Интеграция:
- **D&D5e** - карты работают с системой правил
- **Poker Hand HUD** - отображаются в покерной руке
- **Другие системы** - универсальная совместимость

### 🐛 Устранение неполадок

#### Нет доступных колод:
- Проверьте, что **Cards tab** содержит колоды
- Убедитесь, что в колодах есть **карты**
- Проверьте **права доступа** к картам

#### Карты не добавляются игрокам:
- Убедитесь, что у игроков есть **акторы**
- Проверьте **права на создание** предметов
- Проверьте **систему правил** на совместимость

#### Не отображаются изображения:
- Проверьте, что у карт есть **изображения**
- Убедитесь, что изображения **доступны** всем игрокам
- Проверьте **размеры** изображений
